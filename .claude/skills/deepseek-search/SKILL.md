# Skill: deepseek-search

用于在 `chat.deepseek.com` 中发起搜索类请求，并读取 DeepSeek 返回的结果。

## 触发条件

当用户出现以下任一意图时使用本技能：

- `dp 今天金价`
- `dp 搜一下 A 股`
- `dp 查今天美股走势`
- `dp 总结一下某个新闻`
- `dp 帮我搜并分析`
- 明确要求“用 DeepSeek 搜一下”
- 明确要求“发到 chat.deepseek.com 问一下”

如果用户输入以 `dp ` 开头，默认视为触发本技能。

## 固定工作方式

- 必须使用 `playwright-cli --headed --persistent`。
- 默认站点：`https://chat.deepseek.com`
- 优先复用已有登录态。
- 如果落到登录页，提示用户手动登录；用户回复“已登录”后继续。
- 不要主动手动切换“智能搜索”按钮，默认按页面当前状态执行。
- 如果发送失败或回车没有触发提交，直接点击发送按钮，不要反复切换搜索状态。

## 标准流程

1. 打开 DeepSeek：

```bash
playwright-cli -s=deepseek-search open "https://chat.deepseek.com" --headed --persistent
```

2. 如果页面在登录页：

- 告知用户需要手动登录。
- 登录完成后继续同一会话，不要新开 profile。

3. 进入对话页后：

- 优先点击 `开启新对话`。
- 不要手动点击“智能搜索”按钮，除非用户明确要求切换状态。

4. 将用户 `dp` 后面的内容作为查询主体。

- 如果用户只写了很短一句，例如 `dp A股`，需要自动补全成更明确的问题。
- 补全时要保留用户原意，不要擅自改变任务目标。

5. 发送消息：

- 优先 `fill` 输入框写入完整问题。
- 可以先尝试 `press Enter`。
- 如果消息没有真正发出，改为直接点击发送按钮。

6. 等待返回：

- 通过 `snapshot` 或 `--raw eval` 读取正文。
- 如果页面出现“已阅读 N 个网页”，优先视为已经联网搜索成功。
- 如果回复中明确说“无法联网”“模拟推演”“无法直接实时搜索”，要如实告诉用户。

## 查询补全规则

### 简短查询补全

用户输入较短时，可按下面方式扩展：

- `dp A股`
  扩展为：请搜索并整理今天 A 股市场的最新真实行情，并给出面向普通投资者的结构化分析。

- `dp 金价`
  扩展为：请搜索今天的国际金价与国内金店零售金价，并总结走势、驱动因素和后续观察点。

- `dp 某新闻`
  扩展为：请搜索这条新闻的最新进展、核心信息、不同来源说法差异，并做简要分析。

### 保真原则

- 用户已经写得很完整时，不要大改。
- 用户要求“真实数据”时，问题里必须明确写出：`不要模拟，不要假设`。
- 用户要求“分析”时，要补上：`驱动因素`、`风险点`、`后续观察方向`。

## 输出要求

- 先直接告诉用户 DeepSeek 是否真正联网搜索成功。
- 如果成功，优先提炼：
  - 核心结论
  - 关键数据
  - 主要分析
  - 风险提示
- 必要时附上 1-3 段关键原文，不要整段无差别转储。
- 如果 DeepSeek 明确是模拟结果，要直接说明，不要包装成真实搜索结果。

## 常见异常处理

### 1. 登录页

- 说明当前未登录。
- 提示用户手动登录后回复“已登录”。

### 2. 回车未发送

- 不重复发消息。
- 直接点击发送按钮。

### 3. 误切换智能搜索

- 如果误点导致关闭搜索，重新新建对话再来一次。
- 第二次不要再手动点击“智能搜索”按钮。

### 4. 返回模拟结果

- 明确告诉用户：这不是实时联网结果。
- 如需继续，可重新组织提示词，强调：

```text
请搜索今天的真实数据，不要模拟，不要假设。如果无法联网请直接说明。
```

## 推荐提示词模板

### 通用搜索模板

```text
请搜索并整理以下问题的最新真实信息：<用户问题>。
要求：
1. 优先基于今天可查到的真实网页信息；
2. 不要模拟，不要假设；
3. 先给结论，再给关键数据与来源依据；
4. 如果信息存在分歧，说明分歧点；
5. 如果无法联网或无法确认，请直接说明。
```

### 金融行情模板

```text
请搜索并整理今天的真实行情数据，并给出结构化分析。
要求：
1. 先列关键指数或价格；
2. 再讲板块或相关资产走势；
3. 说明今天涨跌的主要驱动因素；
4. 给出后续观察点、风险点；
5. 不要给绝对买卖指令；
6. 不要模拟，不要假设。
```

## 示例

### 用户输入

```text
dp 今日股价，不同版块今日走势，对后续操作做一个分析
```

### 建议发送给 DeepSeek 的内容

```text
请搜索并整理今天 A 股市场的最新真实行情，并给出面向普通投资者的结构化分析。要求：
1. 先列出上证指数、深证成指、创业板指、科创50 今日真实涨跌情况；
2. 总结不同板块今日真实走势，至少包括银行、保险、券商、半导体、人工智能、算力、消费、医药、新能源、黄金或有色；
3. 说明今天市场上涨或下跌的主要驱动因素；
4. 给出后续操作分析，分别说明短线、中线应如何观察，不要给绝对买卖指令，但要给出风险点与关注方向；
5. 如果有引用数据，请明确是今天的数据，不要模拟，不要假设。
```
