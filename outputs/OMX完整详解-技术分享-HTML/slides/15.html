OH-MY-CODEX / TECHNICAL SHARING

不同工具解决不同层：不要把编排、IDE 与 Agent CLI 混为一类

Codex CLI

直接 Agent CLI

模型调用、读写代码、执行命令。结构最小，适合明确且单一的任务。

OMX

Codex 编排层

在 CLI 之上增加工作流、角色路由、持久状态、Team 协作与验证约束。

Cursor

IDE 中心体验

编辑器、代码浏览与交互式辅助紧密结合，核心入口是图形化 IDE。

Claude Code

另一类 Agent CLI

同样面向终端研发任务，可作为独立工具，也可在可用时参与混合 Worker 路由。

选择标准：你需要的是直接编码、IDE 体验，还是跨任务的编排、状态与团队协作？
比较仅描述产品层级与使用入口，不代表能力强弱排名15
