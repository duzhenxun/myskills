使用说明

  1. 浏览器打开 http://localhost:25259，在「① 注册订阅」页点击 注册推送，弹窗中点击「允许」。
  2. 页面自动生成 subscription 并复制到剪贴板，同时 POST 到 /api/subscribe 落盘 subscriptions.json。
  3. 切到「② 推送测试」页，勾选目标设备 → 选内容模板 → 点发送；结果逐台显示 ✓ HTTP 201 或失败原因。
  4. 手机上要用 HTTPS：npm run cert → HTTPS=1 npm start → 手机访问局域网地址（首次需信任自签证书）。
  5. iOS 必须先把网页「添加到主屏幕」以 PWA 方式打开，才能拿到 Web Push 权限（iOS 16.4+）。
