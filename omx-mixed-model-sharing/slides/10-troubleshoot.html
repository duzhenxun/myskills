FIELD CHECKLIST
MAKE IT BORING
排错按层次，不要盲目重装

先查命令，再查路由，最后查 Team 状态

1 · CLI 层

  • command -v 是否存在
  • 版本命令是否成功
  • 单独登录是否有效
  • tmux 内 PATH 是否一致

2 · 路由层

  • echo $OMX_TEAM_WORKER_CLI_MAP
  • Map 数量是否等于 worker 数
  • 值是否为允许的四种之一
  • Gemini 命令必须是 gemini

3 · Runtime 层

  • 是否在 Git 仓库
  • 是否处于附着 tmux 会话
  • omx team status <name>
  • 任务终态后再 shutdown
