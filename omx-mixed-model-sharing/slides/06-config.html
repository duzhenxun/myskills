把稳定契约写进 shell 环境

最小永久配置：一条 CLI Map

~/.zshrc
# 3 worker 时逐个分配 export OMX_TEAM_WORKER_CLI_MAP="codex,claude,gemini" # 可选：启用运行时动态扩缩容 export OMX_TEAM_SCALING_ENABLED=1
$ source ~/.zshrc

Map 的长度规则

  • 单个值：广播给所有 worker，例如 claude
  • 多个值：数量必须与 worker 数完全一致
  • 5 worker 不能用 3 项 Map 自动循环，需写满 5 项
  • 可用值：auto | codex | claude | gemini
不要依赖：未经当前版本验证的 `.omx-config.json` 自定义字段。
