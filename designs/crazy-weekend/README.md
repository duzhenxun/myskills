# 疯狂周末 - 移动活动页设计稿

本目录提供“疯狂周末”移动活动页的静态设计产物，基于已批准原型整理为可直接查看的 HTML 视觉稿与配套说明文档。

## 文件说明

- `index.html`
  - 主要设计稿文件。
  - 纯静态 HTML + 内联 CSS，无外部依赖。
  - 包含两个主要状态：
    - 未触发双倍
    - 已触发双倍
- `README.md`
  - 当前说明文档，描述设计内容、模块覆盖范围和查看方式。
- `architecture.md`
  - 面向研发评审的系统架构图文档。
  - 包含分层架构、核心时序、数据对象、实时同步点与高风险问题。

## 设计覆盖内容

该设计稿严格围绕需求内模块构建，未扩展额外业务功能。包含以下内容：

1. **Banner A / B 状态**
   - A：未触发双倍，展示主视觉、礼物进度 `0/5`、幸运石数量 `10`
   - B：已触发双倍，展示双倍主视觉和“开出指定礼物双倍获得”文案

2. **顶部个人模块**
   - 礼物进度
   - 幸运石数量
   - 双倍状态

3. **每周重置倒计时**
   - 天 / 时 / 分 / 秒展示
   - 周日 `23:59:59` 清空说明

4. **188 钻玩法礼物参与卡**
   - 188 钻玩法礼物核心说明
   - 主播 1 钻直达、182 钻进入随机玩法奖励池说明
   - 双倍资格说明

5. **奖励池展示**
   - 普通情况
   - 双倍情况

6. **幸运石 9 宫格选择区**
   - 9 个礼物档位完整展示
   - 对应价值 / 倍率 / 产出价格展示
   - `+ / -` 控件视觉表达
   - 多选状态展示

7. **汇总 / 确认区域**
   - 已选礼物数
   - 已投入幸运石数
   - 命中规则 / 双倍说明
   - 提交按钮

8. **确认弹窗 mock**
   - 消耗说明
   - 礼物投放清单
   - 取消 / 确认按钮

9. **边界状态示例**
   - 无幸运石空态
   - 单礼物投放超限提示
   - 周重置公告提示
   - 禁用按钮示例

## 视觉方向

设计按需求建议采用双主题：

- **普通态**：暖橙 / 金色，传达周末开启、送礼累积、氛围热闹
- **双倍态**：红 / 金 / 紫，强调资格解锁、奖励升级、命中刺激感

整体采用：
- 深色夜场背景
- 发光卡片与节庆渐变
- 移动端卡片式信息组织
- 统一圆角、描边、间距体系
